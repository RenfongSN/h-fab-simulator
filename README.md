# H 組晶圓生產區段模擬器

繁體中文、無需安裝的靜態網頁模擬器。直接開啟 `index.html`，或使用 GitHub Pages。

## 功能
- 比較升級前、升級後未控制投入、方案 A、方案 B。
- 可調整到料、加工、搬運、量測、換型及 WIP 參數。
- 顯示完成量、預期合格產出速率、站內與總週期 P95、未完成批次數。
- 匯出逐批 CSV，或恢復簡報預設值。

## 預設結果
120 小時到達 160 批；P95 追蹤全部批次至完成。

| 情況 | 120 小時完成批次 | 總週期 P95（分鐘） | 站內週期 P95（分鐘） |
|---|---:|---:|---:|
| 升級前 | 118 | 2386.0 | 2386.0 |
| 升級後未控制 | 130 | 1612.2 | 1612.2 |
| A 限制投入 | 130 | 1612.2 | 220.0 |
| B 限制投入與量測排序 | 135 | 1252.2 | 265.0 |

## 假設與資料來源
這是 MiniFab 教學案例改編的虛構模型，不是真實工廠預測。加工與搬運時間參考 McGinnis（2023 修訂）。量測換型 5 分鐘移用自 M3 類微影設備的產品切換設定，並非量測設備實測時間。量測 50 分鐘、到料 45 分鐘、WIP 4 批、固定良率 98% 為本組假設。未模擬停機、重工與廠務限額。

- [MiniFab](https://leonmcginnis.com/wp-content/uploads/2023/04/IntelMiniFabCaseStudy02012021.pdf)
- [IEOM 2025 投入控制研究](https://ieomsociety.org/proceedings/singapore2025/86.pdf)

## GitHub Pages 發布
將本資料夾內的 `index.html`、`.nojekyll`、`README.md` 放到 GitHub 儲存庫根目錄。在 Settings → Pages 選擇 Deploy from a branch、main、/ (root)，儲存後等候部署完成。

網頁不使用後端、登入、外部程式庫或追蹤程式。計算與 CSV 產生均在瀏覽器本機完成。
